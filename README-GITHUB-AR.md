# Analytics Pro — بناء APK من GitHub

1. ارفع محتويات هذا المجلد إلى Repository جديد على GitHub.
2. تأكد أن الفرع اسمه `main`.
3. افتح تبويب **Actions**.
4. اختر **Build Analytics Pro APK**.
5. اضغط **Run workflow** إذا لم يبدأ تلقائيًا.
6. بعد نجاح البناء، افتح الـworkflow ثم قسم **Artifacts**.
7. نزّل `Analytics-Pro-debug-apk.zip` واستخرج منه `app-debug.apk`.

لا تحتاج إلى كمبيوتر؛ كل عملية البناء تتم على GitHub Actions.
